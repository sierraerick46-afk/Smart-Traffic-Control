CRISP-ML in the Smart Traffic Light project

CRISP-ML evolves CRISP-DM (Cross Industry Standard Process for Data Mining) for modern machine learning projects. It defines iterative, well-defined phases oriented to results, and adds what CRISP-DM left out: integrating the model into a real system and monitoring it afterwards.
